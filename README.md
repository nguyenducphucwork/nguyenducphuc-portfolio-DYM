# Nguyễn Đức Phúc — Digital Marketing Portfolio

Portfolio một trang với 4 ngôn ngữ Việt–Anh–Nhật–Trung, được thiết kế theo tinh thần agency Nhật Bản: chính xác, hiện đại và tập trung vào kết quả. Thiết kế là bản gốc, không sao chép tài sản thương hiệu hoặc nội dung của DYM Việt Nam.

Website đã tích hợp ảnh chân dung, hồ sơ Outlier, thư viện minh chứng KTDC/ActiX/NUTRO/MOTI và chứng chỉ chuyên môn. Ảnh chứa danh sách thông tin liên hệ bên thứ ba và các chứng chỉ có số định danh cá nhân được giữ ngoài bản website công khai để bảo vệ dữ liệu.

## Xem thử trên máy

Mở `dist/index.html` trực tiếp bằng trình duyệt. Website không cần cài Node.js hay chạy lệnh build.

## Đăng lên GitHub Pages

1. Tạo repository mới trên GitHub, ví dụ `nguyenducphuc-portfolio`.
2. Upload toàn bộ thư mục dự án này lên repository.
3. Vào **Settings → Pages**.
4. Tại **Build and deployment → Source**, chọn **GitHub Actions**.
5. Mở tab **Actions** và chờ workflow `Deploy portfolio to GitHub Pages` hoàn tất.
6. Link thường có dạng `https://TEN-GITHUB.github.io/nguyenducphuc-portfolio/`.

Nếu repository được đặt tên chính xác là `TEN-GITHUB.github.io`, link sẽ rút gọn thành `https://TEN-GITHUB.github.io/`.

## Chỉnh nội dung

- Nội dung trang: `dist/index.html`
- Màu sắc và giao diện: `dist/styles.css`
- Chuyển ngôn ngữ và hiệu ứng: `dist/script.js`
- Ảnh hero: `dist/assets/digital-growth-hero.png`

Trước khi ứng tuyển, nên bổ sung email, LinkedIn, file CV và ảnh minh chứng thật của từng case study nếu muốn nhà tuyển dụng kiểm tra sâu hơn.
